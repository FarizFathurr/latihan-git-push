# Proyek Website Profil

Proyek ini merupakan aplikasi web statis yang dikembangkan untuk mengimplementasikan alur kerja Git/GitHub profesional, manajemen *branching*, serta penyelesaian *merge conflict*.

## 🚀 Fitur & Halaman
- **Halaman Utama (`index.html`)**: Halaman landing page utama proyek.
- **Halaman Profil (`profile.html`)**: Halaman detail informasi dan biodata pengguna.
- **Halaman Tentang Kami (`about.html`)**: Halaman informasi latar belakang proyek.

## 🛠️ Teknologi yang Digunakan
- HTML5 & CSS3
- Git & GitHub (Git Flow Version Control)
