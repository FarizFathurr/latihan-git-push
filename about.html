📖 Tentang Proyek Ini

Mengenal lebih jauh perjalanan latihan web development dan versi kontrol Git.

💡 Perjalanan & Latar Belakang

Proyek ini dibuat sebagai media pembelajaran langsung (*hands-on*) dalam menguasai teknologi pengembangan web modern modern dan fitur-fitur penting Git seperti git commit, git push, serta pengelolaan cabang (branching).

Melalui proyek sederhana ini, target utamanya adalah membangun antarmuka web yang bersih, responsif, dan menyenangkan secara visual menggunakan standar HTML5 dan CSS modern.

🎯 Visi & Misi

🚀 Visi

Menjadi pengembang web profesional yang konsisten menciptakan aplikasi web berestetika tinggi dan berkinerja cepat.

🛠️ Misi

Mengasah keterampilan pemograman setiap hari, menerapkan praktik terbaik (clean code), dan terus belajar teknologi terbaru.
